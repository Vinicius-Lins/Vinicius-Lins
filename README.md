### Nexus Bank

O **Nexus Bank** é um projeto desenvolvido para praticar a criação de uma interface de login moderna e funcional.

O projeto reúne vários conceitos que venho estudando em HTML, CSS e JavaScript:

* Estrutura HTML semântica
* Construção de interfaces
* CSS e responsividade
* Manipulação do DOM
* Eventos
* Funções
* Validação de campos
* Mensagens de erro
* Mensagens de sucesso
* Organização do código

A proposta do projeto é transformar conceitos estudados em uma aplicação prática e utilizável.
